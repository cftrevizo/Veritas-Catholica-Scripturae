# Contributing

Contributions are welcome, especially from biblical scholars, clergy, patristics researchers, textual critics, Catholic apologists, and data engineers.

## Preferred workflow
Open a GitHub Issue for a correction or scholarly judgment. Include:
- source verse/reference
- target verse/reference
- current VCS classification if known
- proposed action: approve, reject, remap, reclassify, or annotate
- primary/secondary evidence and bibliographic citation
- explanation of whether the relationship is quotation, probable allusion, thematic parallel, typology, textual/Septuagint relationship, or another category

## Important distinction
Do not infer that a relationship proves canonicity or doctrine merely because two passages are cross-referenced. VCS aims to preserve the evidence first and interpretation second.

## Data changes
Changes to the master dataset should preserve upstream provenance. Never replace a source relationship with an unattributed edited version.
